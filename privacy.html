목적과 접근 정보

이 개인용 연결 설정은 사용자의 Google Drive를 자신의 노트북 폴더로 이용하기 위해 사용합니다. Google에서 허용한 범위 안에서 파일 내용과 파일·폴더 이름, 크기, 수정 시각 등의 메타데이터에 접근합니다. 사용자가 실행한 파일 조회·열기·저장·생성·수정·이동·삭제 작업을 처리합니다.

보관과 전송

Google Drive의 원본 파일은 Google에 보관됩니다. OAuth 인증 정보와 파일 작업 캐시는 사용자의 노트북에 저장됩니다. 파일 작업에 필요한 데이터는 로컬 rclone 프로그램과 Google 서비스 사이에서 전송됩니다. 이 연결 설정을 위한 별도의 개발자 데이터 수집 서버는 운영하지 않습니다.

로컬 캐시는 프로그램의 캐시 설정에 따라 정리됩니다. 아직 업로드되지 않은 변경사항은 후속 업로드를 위해 남아 있을 수 있습니다. 인증 정보는 사용자가 연결을 해제하거나 로컬 설정을 제거할 때까지 노트북에 보관될 수 있습니다.

Google 사용자 데이터 사용

Google 사용자 데이터는 이 페이지에 설명된 개인용 파일 연결 기능을 제공하는 데 사용됩니다. 별도의 광고, 판매 또는 분석 서비스에 제공하지 않습니다. Google API에서 받은 정보의 사용 및 전송에는 Google API 서비스 사용자 데이터 정책과 해당 제한적 사용 요건이 적용됩니다.

접근 철회와 로컬 데이터 삭제

사용자는 Google 계정의 연결된 앱 관리에서 Linux Laptop Drive의 접근 권한을 철회할 수 있습니다. 노트북의 연결 설정과 로컬 캐시는 업로드할 변경사항이 남아 있지 않은지 확인한 뒤 제거할 수 있습니다. 연결 해제 자체로 Google Drive의 원본 파일이 삭제되지는 않습니다.

안내 사이트와 문의

이 정적 안내 사이트에는 자체 분석 도구나 로그인 기능이 없습니다. 공개 호스팅을 제공하는 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록할 수 있으며, 해당 처리는 GitHub 개인정보처리방침을 따릅니다.

문의처는 Google OAuth 동의 화면에 표시되는 사용자 지원 이메일입니다.
